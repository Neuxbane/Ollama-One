Model IDs & Routing

The model ID fully determines the provider and transport. An optional :function(args) directive may be appended — it is parsed off the ID and applied as middleware before the request is routed.

Quick Start

Point any OpenAI-compatible client at the gateway and pass your Gemini or DeepSeek API key per request. No server-side secrets, no configuration files needed.

Base URLbase_url
https://proxy.ai.sesh.top/v1

Use https://proxy.ai.sesh.top/v1 as the base_url in your client, or POST directly to https://proxy.ai.sesh.top/v1/chat/completions.

Python · OpenAI SDK (DeepSeek + WarpTools)python
from openai import OpenAI

client = OpenAI(
    api_key="YOUR_DEEPSEEK_OR_GEMINI_KEY",
    base_url="https://proxy.ai.sesh.top/v1",
)

resp = client.chat.completions.create(
    model="deepseek-chat:warp_tools(top_k=10)",
    messages=[{"role": "user", "content": "What's the weather in Tokyo?"}],
    tools=massive_tool_catalog,  # 100+ tools indexed locally
)
print(resp.choices[0].message.content)
cURLshell
curl https://proxy.ai.sesh.top/v1/chat/completions \
  -H "Authorization: Bearer $DEEPSEEK_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "deepseek-chat:warp_tools(top_k=10)",
    "messages": [{"role": "user", "content": "Hello WarpGate!"}]
  }'

Authentication (Stateless)

Because WarpGate is strictly stateless, your provider API key (Gemini or DeepSeek) travels with each request. Any of these standard locations work:

MethodExample
Authorization headerAuthorization: Bearer sk-… or Bearer AIzaSy…
Anthropic / Ollama stylex-api-key: sk-…
Google Cloud styleX-Goog-Api-Key: AIzaSy…
Azure / genericapi-key: sk-…
Query parameter?key=… or ?api_key=…
JSON body{ "api_key": "…", … }
⚠️
Placeholder values such as dummy, none, null, ollama, and test are ignored, so clients that require a non-empty key still work.

Dynamic Model Middleware

Append :function(args) directives to a model ID to transform requests on the fly. The base model is resolved automatically.

Syntaxmodel id
REAL_MODEL_ID:FUNCTION_NAME(ARG1, ARG2, …)

# Example 1: DeepSeek with dynamic semantic tool retrieval (auto-bypasses if ≤ 10 tools)
deepseek-chat:warp_tools(top_k=10)

# Example 2: Gemini Live WebSocket model, truncating parts over 4000 chars
google/ws/gemini-3.1-flash-live-preview:truncate(all, 4000)
DirectiveScopeDescription
:warp_tools(top_k=10)toolsDynamic Tool Retrieval: Replaces 100+ tools with searchTools and execute meta-tools using a 100% local semantic vector embedding index. Automatically bypasses when tools ≤ top_k.
:warp_tools(5)toolsShorthand for :warp_tools(top_k=5).
:truncate(all, 4000)allTruncate system prompt, user, assistant, and tool/function content.
:truncate(tools, 2000)toolsTruncate only tool/function responses and arguments.
:truncate(user, 1000)userTruncate only user messages.
:truncate(4000)allShorthand for :truncate(all, 4000).
⚡
WarpTools: Zero external API dependencies. Built-in dense subword character n-gram embeddings and domain synonyms run locally in <1ms. Discovered tool calls are automatically unwrapped to standard native tool calls before returning to the client.

API Reference

WarpGate implements the full OpenAI Chat Completions specification. All endpoints accept the API key locations listed above.

MethodEndpointDescription
POST/v1/chat/completionsCreate a chat completion (streaming SSE or non-streaming).
GET/v1/modelsList all available Gemini and DeepSeek models.
GET/v1/models/{id}Retrieve a single model descriptor.
GET/healthzLiveness probe — returns {"status":"ok","service":"warpgate"}.
🔌
Aliases without the /v1 prefix (/chat/completions, /models) are also served for maximum client compatibility.

Connect VS Code Copilot

Open model management

In Copilot Chat, open the model dropdown and choose Manage Models….

Open the JSON config

In the Language Models tab, click the Open Language Models (JSON) icon.
